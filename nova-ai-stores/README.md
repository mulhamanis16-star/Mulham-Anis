# Nova AI Stores

منصة عربية قيد التطوير لمساعدة أصحاب المتاجر على تجهيز محتوى المنتجات لقنوات البيع المختلفة.

## الحالة الحالية: MVP تجريبي
- واجهة عربية كاملة باتجاه RTL.
- اختيار منصة البيع: نون، أمازون، ترينديول، زد، سلة.
- إنشاء مسودة عنوان ووصف ومميزات وكلمات مفتاحية من المواصفات التي يدخلها المستخدم.
- نسخ المحتوى وتصديره إلى CSV بترميز UTF-8 BOM لفتحه في Excel.
- سجل آخر 30 مسودة منتج مع إمكانية فتحها وحذفها.
- حفظ السجل محلياً في المتصفح باستخدام التخزين المحلي؛ لا تتم مزامنته بين الأجهزة ولا يُرفع إلى خادم.
- إعداد Vite للنشر ضمن GitHub Pages، مع سير عمل بناء ونشر تلقائي عند تحديث ملفات المشروع.
- تحقق أساسي من المدخلات وتصميم متجاوب.

## تشغيل المشروع محلياً
يتطلب Node.js حديثاً وnpm:

```bash
npm install
npm run dev
```

لإنشاء نسخة إنتاجية:
```bash
npm run build
npm run preview
```

## توضيح مهم
المولّد الحالي يعمل محلياً بقواعد نصية تجريبية، وليس نموذج ذكاء اصطناعي ولا يتصل بأي منصة بيع. يجب مراجعة كل مسودة قبل نشرها. لا توجد حالياً حسابات مستخدمين أو قاعدة بيانات أو دفع أو تكاملات API.

## خارطة الطريق
1. تحسين قوالب المحتوى لكل منصة واختبارها.
2. إضافة مكتبة منتجات محفوظة وتصدير XLSX.
3. اختبار عملية النشر على GitHub Pages والتحقق من الرابط العام.
4. بناء واجهة خلفية آمنة وربط مزود ذكاء اصطناعي دون كشف مفاتيح API للمتصفح.
5. إضافة حسابات المستخدمين وقاعدة بيانات ومزامنة آمنة بين الأجهزة.
6. إضافة تصدير XLSX واختبارات أوسع.

لا تضع مفاتيح API أو أسراراً في ملفات الواجهة الأمامية أو مستودع GitHub.
