# NovaStores — مساعد المتاجر الذكي

تطبيق عربي لمساعدة أصحاب المتاجر الإلكترونية على إعداد محتوى المنتجات لقنوات البيع.

**التطبيق:** https://mulhamanis16-star.github.io/Mulham-Anis/

## الوظائف الحالية

- إنشاء عنوان ووصف تسويقي ومميزات وكلمات مفتاحية باستخدام الذكاء الاصطناعي.
- اختيار منصة البيع: نون، أمازون، ترينديول، زد، أو سلة.
- تحليل صورة المنتج لاستخراج وصف بصري للعناصر الظاهرة فقط.
- إدخال المواصفات يدوياً أو لصقها بصيغة: `اسم المنتج | المواصفات`.
- تعبئة بعض الحقول تلقائياً من المعلومات الواضحة في اسم المنتج والمواصفات.
- مؤشر اكتمال يوضح مدى توفر بيانات المنتج، وليس ترتيباً مضموناً في محركات البحث.
- تعديل النص الناتج ونسخه كاملاً أو تصديره إلى CSV.
- إنشاء محتوى دفعي لما يصل إلى 100 منتج في الطلب الواحد.
- حفظ آخر 30 مسودة محلياً في المتصفح الحالي.

## طريقة الاستخدام

1. افتح رابط التطبيق.
2. اكتب اسم المنتج وأدخل المواصفات المؤكدة، أو الصق الاسم والمواصفات مع فاصل `|`.
3. أرفق صورة عند الحاجة.
4. اختر منصة البيع.
5. اضغط «إنشاء المحتوى بالذكاء الاصطناعي».
6. راجع العنوان والوصف والمميزات والكلمات المفتاحية قبل نشرها.

لا يحتاج المستخدم إلى إدخال رابط الخادم أو أي مفتاح API؛ التطبيق يتصل بالخادم المنشور تلقائياً.

## البنية التقنية

- الواجهة: React وTypeScript وVite.
- الاستضافة: GitHub Pages.
- الخادم: Cloudflare Workers.
- الذكاء الاصطناعي: Workers AI، باستخدام GLM-4.7-Flash للنصوص وMoondream 3.1 لتحليل الصور.
- نقطة الاتصال مضبوطة داخل التطبيق، ولا يُكشف أي مفتاح API في المتصفح.

## الخصوصية والبيانات

- سجل المسودات محفوظ محلياً في المتصفح ولا تتم مزامنته بين الأجهزة.
- عند طلب التوليد، تُرسل بيانات المنتج والصورة المرفقة (إن وجدت) إلى خادم NovaStores لمعالجتها.
- لا تدخل بيانات شخصية أو معلومات سرية ضمن مواصفات المنتجات.
- لا تُستخدم اقتراحات النموذج لملء حقول المواصفات المؤكدة أو رفع مؤشر الاكتمال؛ المؤشر يعتمد على بيانات أدخلها المستخدم أو أمكن استخراجها بوضوح من النص.

## حدود الاستخدام

- جودة المخرجات تعتمد على وضوح اسم المنتج ودقة المواصفات.
- تحليل الصورة يصف المظهر الظاهر ولا يثبت الخامة أو المقاس أو الوزن.
- الكلمات المفتاحية اقتراحات مرتبطة ببيانات المنتج، وليست أحجام بحث فعلية أو ضماناً للظهور.
- قد تتأثر الخدمة بحصة Workers AI أو توفر النماذج.
- راجع سياسات منصة البيع ومعلومات المنتج قبل النشر.

## التطوير محلياً

يتطلب Node.js حديثاً وnpm:

```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## النشر

تُبنى الواجهة وتُنشر تلقائياً عبر GitHub Actions عند تحديث ملفات `nova-ai-stores/**`. ويُنشر الخادم عبر سير عمل مستقل عند تحديث `nova-ai-api/**`.

لا تضع مفاتيح API أو أسراراً في ملفات الواجهة الأمامية أو مستودع GitHub.
