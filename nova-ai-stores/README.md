# Nova AI Stores

منصة عربية لمساعدة أصحاب المتاجر الإلكترونية على تجهيز محتوى المنتجات وتحسين صفحات البيع.

## الرؤية
بناء منصة SaaS عربية تخدم بائعي Noon وAmazon وTrendyol وZid وSalla.

## النسخة الأولى
- واجهة عربية RTL
- إدخال بيانات المنتج
- إنشاء مسودة عنوان ووصف ومميزات وكلمات مفتاحية
- نسخ النتائج
- التوسع لاحقاً إلى الذكاء الاصطناعي وتصدير Excel

## التقنية
React + TypeScript + Vite
