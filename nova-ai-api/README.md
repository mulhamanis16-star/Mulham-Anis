# NovaStores API

خادم خلفي لتوليد محتوى المنتجات وتحليل صورها باستخدام Cloudflare Workers AI.

## المكونات

- نموذج النصوص: `@cf/zai-org/glm-4.7-flash`.
- نموذج تحليل الصور: `@cf/moondream/moondream3.1-9B-A2B`.
- ربط Workers AI: `AI`، معرّف في `wrangler.jsonc`.
- النطاق المسموح للواجهة: `https://mulhamanis16-star.github.io`.

## النشر المعتمد

الخادم منشور باسم `bold-bush-b254` على Cloudflare Workers.

رابط الخدمة:
`https://bold-bush-b254.mulhamanis16.workers.dev/`

النشر الآلي يتم عبر GitHub Actions عند تحديث ملفات `nova-ai-api/**`. يحتاج سير العمل إلى السرّين التاليين في إعدادات المستودع:

- `CLOUDFLARE_API_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`

لا تضع قيم هذه الأسرار في ملفات المشروع أو السجلات أو الواجهة الأمامية.

## النشر المحلي (للمطورين)

يتطلب Node.js وnpm وحساب Cloudflare:

```bash
npx wrangler login
cd nova-ai-api
npx wrangler deploy
```

تأكد من بقاء ربط Workers AI باسم `AI` مفعّلاً في `wrangler.jsonc`.

## فحص الخدمة

يمكن فتح رابط الخادم عبر المتصفح باستخدام `GET` للتحقق من أن الخدمة تعمل؛ يعيد الخادم حالة `ok` دون استدعاء نموذج الذكاء الاصطناعي. طلبات التوليد `POST` تُقبل من نطاق تطبيق NovaStores المنشور فقط.

## واجهة الطلب

يستقبل الخادم طلب `POST` بصيغة JSON:

```json
{
  "name": "اسم المنتج",
  "details": "المواصفات المؤكدة",
  "platform": "نون",
  "imageDataUrl": "data:image/jpeg;base64,..."
}
```

حقل `imageDataUrl` اختياري. المنصات المدعومة: نون، أمازون، ترينديول، زد، سلة.

يرجع الخادم JSON يتضمن العنوان والوصف والمميزات والكلمات المفتاحية والعناوين البديلة وحقول معلومات المنتج.

## ضوابط الأمان والجودة

- يقبل طلبات المتصفح من نطاق التطبيق المحدد فقط.
- يتحقق من صيغة الصورة وحجمها ومنصة البيع.
- يرفض بعض حالات تعارض نوع المنتج بين الاسم والمواصفات.
- لا ينبغي تخمين الخامة أو المقاس أو الوزن أو اللون أو بلد المنشأ أو الضمان أو محتويات العبوة.
- مخرجات الذكاء الاصطناعي مسودات تحتاج إلى مراجعة قبل النشر.
- لا ترسل بيانات شخصية أو سرية ضمن تفاصيل المنتجات.

## الحصة والتكلفة

استخدام Workers AI يخضع لحصة الحساب وأسعار Cloudflare الحالية. قد تتوقف الطلبات مؤقتاً عند نفاد الحصة أو تعذر توفر النموذج.
